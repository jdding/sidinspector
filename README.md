# Lifecycle OPE Preflight

This repository tracks the public-data preflight for lifecycle-stratified off-policy evaluation (OPE) in sequential recommendation.

The current goal is to validate the methodology on public datasets before any production deployment or internal business-data study.

## Current Thesis

Lifecycle transitions can create structured support and positivity failures. Aggregate OPE may look credible while specific lifecycle states have weak overlap, high variance, or invalid counterfactual support.

## Stage Boundary

This repository currently covers public research only. No Huawei business data or internal logs should be committed here.
