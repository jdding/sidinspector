# AUDIT-SID External Simulated Review Plan

Timestamp: 2026-05-19 14:28:00 CST

Target venue/track: CIKM 2026 Resource Track.

External target: 8.0 / 10.

## Review Policy

The external simulated review stage should use the same acceptance bar as the
internal polishing stage. The target is not "barely acceptable" or "7.5 if
sympathetic"; the draft should be revised until an external Resource Track
reviewer can plausibly score it at 8/10.

## Reviewer Roles

1. **Resource/artifact reviewer.** Focus on artifact availability,
   quickstart/license, reproducibility, documentation, maintenance, manifest
   quality, and whether the PDF makes the resource value visible within the
   four-page body.

2. **SID/recommender reviewer.** Focus on SID taxonomy, method
   representativeness, diagnostic validity, proxy/misattribution risks, D1--D5a
   sufficiency, and whether the same-item Musical case study supports a Resource
   Track claim.

## Required Output

Each simulated review must report:

- 1--10 score and whether it reaches 8/10;
- P0/P1/P2 issues, where P0 blocks the external 8/10 target;
- which issues can be fixed by writing/table/artifact documentation;
- which issues require new experiments;
- minimal edits needed to reach or preserve the 8/10 target.

## Absorption Rule

Only absorb changes that improve external-review score without strengthening
claims beyond current evidence. If a reviewer asks for a stronger benchmark or
downstream Recall/NDCG claim, treat it as a future-work request unless it is
required for Resource Track credibility.
